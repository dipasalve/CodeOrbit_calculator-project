# Simple Calculator Using Python

## About Project

This is a simple calculator project developed using Python and Tkinter.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear button
* Simple graphical user interface

## Technology Used

* Python
* Tkinter

## How to Run

1. Install Python on your computer.
2. Download the `calculator_gui.py` file.
3. Open CMD in the project folder.
4. Run the following command:


python calculator_gui.py
